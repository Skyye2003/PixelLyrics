PixelLyrics v0.2.0 支持自动识别 QQ 音乐与网易云音乐，运行中保存设置实时生效，并加入歌词来源试用、确认和历史记录。

## 下载

- **PixelLyrics-0.2.0-Setup-win-x64.exe**：推荐安装版，内置可选的网易云同步组件及运行库，无需用户另行下载插件。已有组件会经过检查，避免覆盖用户修改。
- **PixelLyrics-0.2.0-win-x64.exe**：Windows x64 自包含便携版，无需另装 .NET；网易云同步仍需安装组件。
- **component-source.zip / THIRD_PARTY.md / PixelBar-MIT.txt**：组件对应源码与第三方许可。
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验值。

## 主要更新

- 自动识别正在播放的 QQ 音乐或网易云音乐，支持运行中保存并应用设置。
- 可选择登录后启动到托盘和打开应用后自动运行；旧配置默认不开启自动运行，开启并保存即授权后续启动联网取词及 USB 输出。
- 临时接口故障采用有限重试和冷却恢复，提供具体失败原因；设备断开时等待重连，恢复后重新核验曲目及进度。
- 支持跨平台搜索、临时试用歌词及确认来源，只保存映射，不缓存歌词正文。非 Live 候选可通过试听确认；Live 版本冲突和时长差超限仍拒绝。
- 可试用候选优先显示，再按歌曲身份匹配评分与时长差排序，默认选中第一项可试用结果。
- 历史记录支持搜索、分页、多选、批量忽略；相同显示信息归组，不因时长变化在两类列表重复显示，也不自动把映射套用给其他时长。
- 统一按钮、图标、悬停和间距，加入嵌入 EXE 的 PixelLyrics 专用通知音。

## 兼容与限制

- 适用 Windows x64；网易云组件组合此前实测客户端为 **3.1.41.205564 x64**，其他版本未承诺兼容。
- 网易云依赖随安装包提供的 BetterNCM 1.3.4 与 InfLink-rs 3.4.0；安装组件前需完全退出网易云。BetterNCM 自带在线更新与插件商店机制。
- 站点歌词接口可能变化；候选排序不代表歌词存在或时间轴已确认，需实际试用。
- 正常停止、退出及系统暂停时尝试回钟；设备已断开、突然断电或系统提前终止时，软件不能保证清除屏幕。
- EXE 未签名，Windows 可能提示未知发布者。私有仓库的 Release 下载需要仓库访问权限。
