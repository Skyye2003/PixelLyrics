# 网易云接入验证记录

2026-11-15，经用户授权验证官方站点匿名歌曲详情、搜索和歌词接口。无 Cookie、无登录、无账号访问；歌词仅在内存解析，不保存正文，不写 USB，不修改自启。

## 已实现

- 独立 .NET 歌词客户端，通过 `music.163.com` 的 `/api/song/detail/`、`/api/search/get` 和 `/api/song/lyric` 请求数据。无代理、重定向、自动重试或额外 Node.js 服务。
- 优先使用组件 SMTC 的 `NCM-{ID}`，核验歌名、歌手、专辑、版本与时长后取普通 LRC；无 ID 时执行有限搜索及候选详情核验。时长毫秒转换为秒。
- 界面及 `--player qqmusic|netease` 选择播放器；运行期间固定，切换清除授权。旧配置默认 QQ，QQ 绑定与网易云数字 ID 分离保存。
- 请求前再次检查当前曲目、来源 ID、媒体版本、播放进度与运行状态；请求完成后再读会话，旧结果不能用于新曲目。
- 无会话、多会话、过期进度、业务码错误、HTTP 错误、无歌词及损坏 LRC 分别处理。协议或网络故障停止本次后续联网；错误和恢复动作在运行状态中可见。

## 真实接口验证

公开歌曲 ID `454549729`：详情成功，时长 237.113 秒，歌手数量 1、专辑非空；匿名搜索中再次核验此 ID 成功；普通 LRC 解析为 79 行。未输出或保存歌词正文。此结果证明本次网络环境和该歌曲可用，不代表所有歌曲或长期接口稳定性。

真实 `--online --follow --player netease --duration 12`（无 `--send`）同时发现 QQ 与网易云两个会话，正确跟随网易云并启动核验。当前公开歌曲 ID `2024659883` 详情有效，时长 164 秒，但 LRC 首行时间标签形如 `[00:00.00-1]`，不符合当前普通 LRC 解析规则；其余可解析行数为 4。程序拒绝整份歌词并锁止后续请求，没有猜测时间、部分播放或写屏。

### `[00:00.00-1]` 调查与兼容（2026-11-16）

- 来源已确认：官方歌词接口 `/api/song/lyric?id=2024659883&lv=-1&kv=0&tv=0&rv=0` 的 `lrc.lyric` 直接包含该标签（`lrc.version = 3`），不是 PixelLyrics 或进度桥接组件生成的。它所在的首行是作曲署名。未保存歌词正文；测试样本保留实际五行的时间标签，正文替换为合成文本。
- 官方网页播放器的 [JS 资源](https://s3.music.126.net/web/s/pt_frame_index_f8fa68369f5c6b260f4bdd85eeb5f954.js) 中，歌词解析函数 `gO0e.bFY4a` 使用 `xh4e * 60 + parseFloat(bw6a.join(".")) + bo2C / 1e3`。该标签的秒数字符串为 `00.00-1`；`parseFloat` 读取有效数字前缀得到 0，忽略剩余后缀。独立执行同一表达式得到 0 秒。
- 因而已证实的是该标签在官方网页播放器中的时间解释为 0 秒；没有找到官方文档定义 `-1` 的来源或业务含义，不能将其解释为减一秒、减一毫秒或某种通用标志。也不能据此认定是谁写入了该后缀。
- 仅在网易云客户端中，将行首精确的 `[00:00.00-1]` 转为 `[00:00.00]` 后交给原有解析器；保留原始响应文本于内存，其他时间标签和歌词正文不作替换。QQ 与本地通用解析规则不变。`[00:00.00-2]`、`[00:12.00-1]`、`[00:00.00-1x]` 等未经核实写法继续拒绝。
- 修复后再次通过产品客户端匿名请求同一歌曲：详情时长 164 秒，普通 LRC 成功解析 5 行，时间为 0、159、160、161、162 秒。没有写屏；这验证了真实接口解析，不代表设备同步精度或所有歌词格式已验收。

客户端可访问不能等同于所有歌词可解析；其余异常格式仍明确报错并锁止本次后续请求。
