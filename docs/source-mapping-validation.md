# 歌词试用与来源历史

本轮在真实仓库中接入试用、确认来源和历史窗口。自动匹配规则不变；手选试用允许歌手名单不完整、专辑缺失，非 Live 候选允许标题和编曲差异由试听确认，仍要求有效时长且差值不超过 5 秒；Live 候选继续核验歌名主体及版本。明确不同 Live 专辑或演出、录音室与 Live 混用继续拒绝。元数据检查不能证明音频录音一致，用户需试听时间轴后确认。

## 操作

1. 运行中打开选择歌词来源，选择 QQ 或网易云，搜索或粘贴对应平台完整 HTTPS 歌曲链接。
2. 点击试用这版歌词，仅当前歌曲临时使用；未确认不会写入已记住来源。
3. 时间轴合适后点击合适，记住来源。以后播放同曲按映射重新核验和取词。
4. 切歌后从顶部历史记录进入待确认列表；旧曲确认只保存旧曲映射，不替换当前歌词。重新试用需先播放该曲。
5. 停止试用保留历史；忘记来源需确认删除后恢复自动匹配。

来源历史保存于配置路径加 `.sources.json` 的文件，保留播放平台及完整歌曲身份；列表按播放平台、歌名、歌手及专辑归组，时长不同不会自动共用映射，包含歌曲元数据、目标平台与歌曲 ID、确认状态及时间，不保存歌词正文。临时歌词只在运行内存中使用。

## 实机验收

播放待选歌曲并试用同版候选，检查实际时间轴；确认后重启播放同曲，检查映射复用。再试用另一首歌后切歌，在历史确认原曲，检查当前歌词不被覆盖。检查停止试用、关闭选择窗口、重启后待确认保留，以及浅深主题和键盘焦点。不同演出、时长超限仍应拒绝。
