# 网易云进度组件实机测试

## 范围与环境

用户授权安装并测试进度组件。未请求歌词接口，未运行 PixelLyrics USB 输出或写入自启。

- Windows 10，10.0.19045。
- BetterNCM 1.3.4 x64；InfLink-rs 3.4.0，附件哈希见组件调研文档。
- 安装前无 `D:/Program/CloudMusic/msimg32.dll`、无 `C:/betterncm`，无自定义 BETTERNCM_PROFILE；不存在被覆盖文件。
- 新增框架文件 `D:/Program/CloudMusic/msimg32.dll` 和插件 `C:/betterncm/plugins/InfLink-rs.plugin`。框架启动后自行产生 PluginMarket 和插件运行目录。测试结束未卸载。
- 网易云退出后安装；重新启动后观察到版本为 **3.1.41.205564**，与此前原生诊断的 **3.1.33.205244** 不同。未执行播放器升级命令，版本变化原因未核实。不得把本轮结果写成 3.1.33 已通过，亦不能将前后差异全部归因于插件。
- 只读进程模块检查确认网易云加载了安装目录的框架 DLL 及 InfLink-rs x64 后端。

用户确认已播放在线歌曲，采样 65.594 秒，66 个样本全部有效；同场可见 1 个 QQ 会话及 1 个网易云会话，没有串选。

- 歌名、歌手、专辑可读取，总时长为 232166 ms。
- 位置从 43590 ms 增至 108600 ms，净推进 65010 ms。
- 采样时的时间线年龄最大为 1996.9292 ms，未超过现有 5 秒期限。观测更新间隔存在约 2 秒的情况，不宣称严格每秒更新。
- 播放状态持续为 Playing。

## 结论与后续

**网易云 3.1.41.205564 x64 + BetterNCM 1.3.4 x64 + InfLink-rs 3.4.0 已通过本轮进度桥接基础实测**，可作为后续 PixelLyrics 接入的候选组合。3.1.33 未完成插件组合验证；其他版本不扩展声称支持。

后续已完成匿名歌词 API 的固定歌曲调用、PixelLyrics 真实会话跟随与当前曲目格式错误锁止验证，详情及限制见 [接入验证](netease-api-integration.md)。尚未完成 USB 输出、安装包在干净机器上的离线安装/升级/回滚/卸载，以及 GPL 对应源码交付材料。当前不发布 v0.2.0 支持声明。

原始曲目日志保存在本地忽略目录 `release/netease-plugin-playing.jsonl` 和 `release/netease-plugin-actions.jsonl`，不纳入仓库。只读诊断已补充输出 NCM 歌曲 ID，用于验证精确歌曲身份。
