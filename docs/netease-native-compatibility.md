# 网易云原生媒体会话兼容性实测

结论：本机环境未通过原生同步门槛，停止后续网易云歌词与界面接入，不发布 v0.2.0 支持声明。

## 环境与方法

- Windows 10，系统版本 10.0.19045。
- 网易云音乐 3.1.33.205244；用户确认已经播放。
- QQ 音乐同时运行，采样全程可见 1 个 QQ 会话及 1 个网易云会话。
- 使用 `--diagnose-netease` 只读 Windows GSMTC，连续采样 65.630 秒，共 66 个网易云样本。
- 未联网取词、访问 USB、修改播放器或写入自启配置；未检查客户端插件安装状态。

## 结果

| 字段 | 66 个样本的结果 |
| --- | --- |
| 会话标识 | `cloudmusic.exe` |
| 歌名、歌手 | 可读且两次读取一致 |
| 播放状态 | 全部为 `Playing` |
| 专辑 | 全部为空 |
| 播放位置 | 全部为 0 ms |
| 时间线起点、终点 | 全部为 0 ms |
| 时间线更新时间 | 全部为默认值 1601-01-01 |
| 可用时间线 | 0 / 66 |

该结果证明本机已播放场景下无法从原生会话获得同步所需的有效进度，并非会话权限错误。仅歌名与歌手不足以实现可靠歌词同步；不以本地计时推测播放位置。

本结论适用于上述版本和本机环境，不能推断所有网易云版本均不支持。暂停恢复、前后拖动及切歌未继续验证：连续播放阶段已经缺失必需时间线。若后续更换客户端版本或相关系统媒体设置，需重新完成全部兼容性验证后再继续接入。

原始日志位于本地忽略目录 `release/netease-native-playing.jsonl`，包含曲目信息，不纳入仓库。现有 QQ 功能保持不变。
