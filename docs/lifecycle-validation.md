# 自动运行与设备生命周期验证

测试构建：0.2.0-rc.4，2026-11-21。

## 行为

- 高级页分别控制登录后启动到托盘和打开应用后自动运行。自动运行默认关闭；开启并保存即明确授权后续启动联网获取歌词和 USB 输出，包括手动打开应用。
- 保存时从关闭改为开启会启动任务；关闭不停止当前任务。手动停止后，普通保存、重新加载、设备恢复或系统恢复均不自动启动。下次打开应用仍按已保存开关执行。
- 未连接设备时保持任务等待，不发取词请求。只接受唯一严格匹配端点，稳定一秒后重新读取曲目和进度；设备事件及五秒轮询检测连接状态。
- 写入失败后允许一次重新校验；再失败需观察到设备拔除后才恢复。保存设置和恢复连接保留当前运行的接口访问限制与冷却。
- 停止和正常退出尝试回钟；系统暂停或会话结束通知唤醒同一写入循环尝试回钟。单报告写入超时 500 ms，系统通知等待上限两秒；操作系统可能提前终止程序，不能保证发送或实际显示。
- 暂停和恢复递增生命周期版本，旧结果不采用；重新核验后不重播已有歌曲的开场。启动时未连接设备不会使首次正常开场被跳过。

## 离线验证

- Probe 自测：367 项，包括新加入的连接稳定性、多设备冲突、失败重绑定上限、拔插恢复、重新输出、暂停拒绝旧结果、停止后恢复、事件唤醒、自动启动条件及配置兼容。
- OnlineProbe：162 项，内存假响应，无真实联网。
- Core：59 项断言。
- Windows x64 自包含单文件发布及安装包构建；发布 EXE 执行同一离线自测。安装包包含现有网易云可选组件。

## 尚待实测

本轮没有安装测试包、修改登录自启注册表、真实取词、写 USB、触发休眠/注销/关机，也没有完成实际窗口视觉检查。上述离线结果不能替代硬件与系统行为验收。

安装测试包后按以下顺序验收：

1. 旧配置首次打开不自动运行；手动授权可开始。
2. 开启两个启动选项并保存后开始同步。退出重开及重新登录均按设置运行。
3. 手动停止后拔插设备、保存其他参数和休眠恢复，任务保持停止；再次点击开始才恢复。
4. 运行中拔除设备应显示等待，插回后跟随当前播放进度，不输出旧歌曲；多个匹配屏幕时提示冲突。
5. 正常停止、退出、休眠和关机时观察设备是否回钟；恢复后重新跟随。突然断电或设备已经断开无法靠软件保证回钟。
6. 关闭自动运行并保存不打断当前运行；退出重开后需要本次授权。
